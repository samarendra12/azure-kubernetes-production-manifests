# Azure Kubernetes Production Manifests
### Standardized Kubernetes Architecture Manifests for Enterprise AKS Clusters

[![Kubernetes](https://img.shields.io/badge/Kubernetes-Production_Manifests-326CE5?style=for-the-badge&logo=kubernetes&logoColor=white)](https://kubernetes.io/)

Curated collection of production-grade manifests:
- **Deployments**: Multi-replica deployments with rolling update strategies and resource limits.
- **Ingress**: Ingress routing with TLS termination and path-based routing.
- **PersistentVolumes**: Dynamic volume provisioning backed by Azure Managed Disks & Azure Files.
- **Services**: ClusterIP, NodePort, and LoadBalancer abstractions.
